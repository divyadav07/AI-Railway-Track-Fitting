# AI Railway - Frontend

React + Vite + Tailwind frontend for the AI Railway Track Fitting app.
Talks to the Node/Express backend (`/api/signUp`, `/api/login`, `/api/getUsers`).

## Setup

```bash
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` to point to your backend (default `http://localhost:5000/api`).
